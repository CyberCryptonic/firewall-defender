# Firewall Defender: Cyber Breach

## 1. Project Overview
**Firewall Defender: Cyber Breach** is a custom browser game created for a Digital Toolbox final assignment. The project was designed to be easy to run, easy to review, and ready to publish as a static GitHub Pages site.

## 2. Game Story
You play as a cyber defender protecting a school network during an active attack. Malware spreads through the system, phishing traps block safe routes, and a final breach threatens the network core. Your mission is to secure each zone before the attack reaches critical systems.

## 3. How to Play
- Collect all required security items in each level.
- Avoid malware and other hazards that damage your system integrity.
- Reach the glowing server exit after all required items are collected.
- Complete all **5 levels** to secure the network and trigger the final victory screen.

## 4. Controls
- **Movement:** `WASD` or `Arrow Keys`
- **UI Buttons:** **Start**, **Restart**, and **Play Again**

## 5. Level Breakdown
1. **Network Login**
2. **Malware Maze**
3. **Phishing Storm**
4. **Patch Rush**
5. **Core Lockdown**

## 6. Features
- 5 playable levels with progressive challenge
- Cyber-themed visual style
- Animated HUD
- Collectible effects
- Damage feedback
- Level progression tracking
- Final victory screen after Level 5
- GitHub Pages deployment support

## 7. Security and Privacy
This project is a **low-risk static site design** for class use, not a claim of perfect security.

- Built with static **HTML, CSS, and JavaScript** only
- No backend services
- No login/auth system
- No forms
- No uploads
- No tracking or analytics
- No external API calls
- No secrets required to run

## 8. How to Run Locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.
