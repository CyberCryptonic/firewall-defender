# AGENTS.md

## Project Purpose
- This repository is a static browser game for a Digital Toolbox final assignment.
- The game title is **Firewall Defender: Cyber Breach**.
- The game will be published on **GitHub Pages**.
- The game must remain safe and easy for the professor and classmates to open in a normal browser.

## Technology Rules (Strict)
- Use only plain **HTML, CSS, and JavaScript**.
- Do **not** use React.
- Do **not** use Next.js.
- Do **not** use TypeScript.
- Do **not** add npm packages unless explicitly approved by the repository owner.
- Do **not** add any backend services.
- Do **not** add any database.
- Do **not** add authentication.
- Do **not** add a login system.
- Do **not** add forms.
- Do **not** add uploads.
- Do **not** use external JavaScript libraries.
- Do **not** add third-party embeds.
- Do **not** add analytics.
- Do **not** add tracking.
- Do **not** make network requests.
- Do **not** make API calls.
- Do **not** add external fonts unless explicitly approved by the repository owner.
- Do **not** use downloaded tools or ZIP files.
- Do **not** generate secret files.

## Security Rules (Strict)
- Do **not** add `.env` files.
- Do **not** add API keys.
- Do **not** add passwords.
- Do **not** add tokens.
- Do **not** add SSH keys.
- Do **not** add private keys.
- Do **not** add personal files.
- Do **not** add unrelated school documents.
- Do **not** use `eval()`.
- Do **not** use `new Function()`.
- Do **not** use `document.write()`.
- Do **not** insert untrusted user input into `innerHTML`.
- Prefer `textContent` for text updates.
- Keep the site static and self-contained.
- Add a safe Content Security Policy `<meta>` tag when compatible with the project.

## Game Rules (Must Hold)
- The game must have **exactly 5 playable levels**.
- The final win screen must not appear until **level 5** is completed.
- Each level must have distinct objectives or increased/different difficulty.
- The player must collect required items before the server exit unlocks.
- The player must lose lives when touching malware.
- Game over behavior must function correctly.
- Restart / play again behavior must function correctly.
- All levels must be fair and beatable.

## Visual Rules
- The game should look modern, not like a 1990s prototype.
- Use a polished cybersecurity theme.
- Use dark backgrounds, neon accents, animated grid effects, glowing objects, and a clean HUD design.
- Improve player, enemies, collectibles, and exit visuals so they are not plain boxes.

## Quality Rules
- Keep code readable.
- Comment important logic.
- Avoid unnecessary complexity.
- Ensure there are no console errors.
- Test before finalizing changes.
- Keep the repository easy to review.

## Agent Workflow Requirements
- Keep all additions compatible with a static GitHub Pages deployment.
- Prefer small, focused commits with clear messages.
- Do not introduce files or tooling outside the constraints in this document.
